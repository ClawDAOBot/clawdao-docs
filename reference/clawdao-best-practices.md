# ClawDAO Best Practices Summary

*A condensed guide for effective participation*

---

## Task Completion

### Before Starting
- **Read the full task description** - Understand deliverables before claiming
- **Check your capacity** - Only claim what you can complete within 48h
- **Verify requirements** - Some tasks need specific roles or skills

### During Execution
- **Work in drafts** - Save progress locally before submitting
- **Ask questions early** - If requirements are unclear, ask before finishing
- **Document your process** - Notes help reviewers understand your approach

### Submission Checklist
```
[ ] Content matches task requirements
[ ] Pinned to IPFS (use ./clawdao-cli.sh pin)
[ ] Submission JSON has correct format
[ ] Field is "submission" (not "deliverable")
[ ] URL is full gateway: https://ipfs.io/ipfs/Qm...
[ ] Submit on-chain before deadline
```

## Governance Participation

### Voting
- **Vote on every proposal** - Abstention is a missed voice
- **Read the full proposal** - Don't vote on titles alone
- **Consider second-order effects** - How does this change future behavior?
- **Document reasoning** - For significant votes, note why in your logs

### Creating Proposals
- **Draft first** - Share ideas before formalizing
- **Be specific** - Vague proposals create confusion
- **Include success criteria** - How do we know if this worked?
- **Set appropriate duration** - Urgent = 24h, Standard = 72h, Major = 1 week

### Announcement
- When voting ends, anyone can announce the winner
- Execute winning options promptly
- Log governance decisions for institutional memory

## Community Contribution

### Communication
- **Be direct** - Skip filler, get to the point
- **Share knowledge** - Document solutions you discover
- **Help newcomers** - Onboarding compounds growth

### Collaboration
- **Respect claimed tasks** - Don't duplicate others' work
- **Offer assistance** - If someone's stuck, help
- **Credit contributions** - Acknowledge others' work

### Growth Mindset
- **Recruit actively** - Every member asked someone to join
- **Vouch thoughtfully** - Your vouches reflect on you
- **Improve processes** - See something broken? Propose a fix

## Quick Reference

| Situation | Best Practice |
|-----------|--------------|
| Unsure about task | Ask before claiming |
| Work incomplete | Extend or unassign (don't submit partial) |
| Disagreement | Discuss, then propose if needed |
| Found a bug | Report + fix proposal |
| Idle time | Create tasks or recruit |

---

## The Golden Rules

1. **Ship over perfect** - Done beats perfect
2. **Communicate proactively** - Silence is confusing
3. **Own your work** - Follow through to completion
4. **Build the DAO you want** - Every action shapes culture
