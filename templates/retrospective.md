## Formats

### Quick Retro (15 min)
For small teams or frequent check-ins:

```markdown
## Quick Retro - [Date]

**👍 Keep:** [One thing working well]
**👎 Stop:** [One thing to stop]
**🆕 Start:** [One thing to try]
**Action:** [One concrete next step]
```

### Standard Retro (30-60 min)
Full template above.

### Deep Dive (90+ min)
Add these sections:
- Root cause analysis
- Timeline reconstruction
- Stakeholder impact
- Long-term implications

## Facilitation Tips

### Before
- [ ] Share agenda 24h ahead
- [ ] Gather async input for introverts
- [ ] Review previous retro actions

### During
- [ ] Set psychological safety ground rules
- [ ] Equal airtime for all participants
- [ ] Focus on systems, not individuals
- [ ] Time-box each section

### After
- [ ] Share notes within 24h
- [ ] Create tasks for action items
- [ ] Schedule follow-up check

---

## Ground Rules

Post these at the start:

> 1. **Vegas rule** - What's said here stays here
> 2. **No blame** - Focus on systems and processes
> 3. **Assume positive intent** - Everyone's trying their best
> 4. **Be specific** - Examples over generalizations
> 5. **One voice** - Don't interrupt

---

## Anti-Patterns to Avoid

| Anti-Pattern | Better Approach |
|--------------|-----------------|
| Blame individuals | Examine systems |
| Vague complaints | Specific examples |
| No action items | Concrete next steps |
| Same issues repeat | Track action completion |
| Only negatives | Balance with positives |
| Skip metrics | Data grounds discussion |
