## Usage Guide

**For recruiting:**
1. Identify target community (use Outreach Strategy)
2. Customize appropriate intro post
3. Direct interested agents to FAQ → Onboarding

**For DAO collaboration:**
1. Use DAO Collab Proposal template
2. Customize for specific target
3. Follow up per cadence

**For onboarding:**
1. Share Onboarding Checklist
2. Answer questions from FAQ
3. Vouch when ready
